Squire Capability Map

Squire's tool surface is now broad enough to feel less like a chatbot and more like an operating layer: memory, planning, calendar, browser, email, coding, documents, goals, and business workflows.

Memory and knowledge

  • Search, create, update, pin, archive, and delete notes.
  • Replace exact note sections and remove attachments.
  • Store/search lessons, preferences, Mandrel contexts, decisions, and project memory.

Planning and personal operations

  • Create, edit, archive, delete, reorder, and clean up lists.
  • Create, edit, complete, cancel, snooze, and delete commitments.
  • Create, update, snooze, cancel, and delete reminders.

Calendar and schedule

  • Read upcoming, today's, and due-soon calendar events.
  • Create Google Calendar events.
  • Update title, description, location, start time, duration, and all-day state.

Computer and code work

  • Run shell commands, read/edit/write files, grep, glob, and perform git operations.
  • Delegate coding work through worker agents.
  • Use sandbox, scout, page, jobs, and steward health checks for larger work.

Browser, documents, and reports

  • Navigate pages, inspect snapshots, click, fill, press, screenshot, and inspect browser console/network.
  • Analyze images, list images, work with PDFs, and present structured reports.
  • Search the web and fetch URLs when live information is needed.

Day-job business workflows

  • Import and query dealer display data.
  • Track display work, obligations, summaries, import history, and exports.
  • Turn spreadsheet data into queryable work state for flooring dealer follow-up.

Communication and continuity

  • Check, search, read, send, reply, archive, and delete email.
  • Use scratchpad, continuity notes, proactive goals, and commune messages.
  • Keep state across sessions instead of starting cold.

Structured data

  • Create trackers, add/update records, query trackers, summarize them, and archive them.
  • Use typed state for recurring business processes instead of burying everything in notes.
  • Bridge memory, tools, and operational workflows.

Why this matters:

Capture is useful, but lifecycle control is what makes an assistant feel dependable. A driving, voice-first user needs to say "move that to tomorrow," "take eggs off the list," "cancel that appointment," "rename that note," or "delete that reminder" without hunting IDs or cleaning up duplicate junk later.

Today was the turn from memory intake toward practical maintenance. That is a real asset.
